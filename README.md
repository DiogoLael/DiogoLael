# Engenharia e Desenvolvimento Aplicado a ERP 🛠️

Desenvolvedor de software e graduando em Engenharia, focado na criação de ferramentas de automação, monitoramento e middleware para o ecossistema **TOTVS WinThor** e infraestrutura de TI.

Desenvolvo soluções em Java para simplificar a análise técnica de banco de dados e otimizar rotinas de faturamento e estoque em distribuidoras.

### ⚡ O que eu desenvolvo para a operação:

*   **Soluções para o Ecossistema WinThor:** Criação de ferramentas que rodam queries SQL nativas nas tabelas centrais (`PCPRODUT`, `PCEST`, `PCPEDC`) para auditar saldos, identificar divergências lógicas e simular a liberação de travas de vendas (Rotina 316).
*   **Automação de Infraestrutura:** Implementação de microsserviços para monitoramento de saúde de servidores (uso de memória/CPU), validação automatizada de rotinas de backup e testes de conectividade de rede.
*   **Stack Técnica:** Java, Spring Boot (Data JPA), Oracle SQL / H2 Database, Docker, Docker Compose, Linux, e arquiteturas com Redis (Cache) e MongoDB (Logs de integração).

---
**Foco:** Criar software inteligente que previne lentidão, evita perda de dados e acelera o diagnóstico técnico da equipe de TI de empresas que utilizam ERP.
